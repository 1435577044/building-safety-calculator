# 施工安全设施计算软件

> 依据现行国家 / 行业标准条文**独立实现**的施工安全设施计算软件。
> 全部公式、判定阈值、条文引用均取自公开标准原文，**不包含任何商业软件的代码、算法、数据或素材**。

---

## 一、快速开始

### 方式 A：单文件便携版（推荐，双击即用，可单文件分发）

```
dist-portable/建筑安全计算软件-v2.3.0-单文件便携版.exe
```

- **只需这一个 exe**，约 80 MB；Electron 运行时、ffmpeg.dll 等全部依赖、
  应用代码与规范数据都封装在内，**复制到任意目录 / U 盘 / 其它电脑，双击直接运行**，
  不会出现「找不到 ffmpeg.dll」之类缺依赖的问题；
- 首次启动时自动解压到系统临时目录运行，无需安装、无需联网、无需 Node 环境；
- 计算书导出到「文档 / 建筑安全计算软件计算书」；
- 窗口大小与位置会自动记忆；`Ctrl+R` 重新加载，`F12` 开发者工具；
- 标题栏右侧 `☾ / ☀` 切换白天 / 黑夜模式，选择自动保存；
- 左侧专业树可折叠分组，右侧结果概览实时显示验算结论与不满足项。

> 客户端采用 `safecalc://` 本地协议读取内置资源，规避了 `file://` 下浏览器拦截 JSON 的问题。
> 渲染进程禁用 Node 集成，并做了目录穿越防护与外链拦截。

### 方式 B：目录版客户端（便于二次开发与排查）

```
双击工程根目录的「启动客户端.bat」
  或直接运行 dist-client/建筑安全计算软件.exe
```

目录版需**整个目录一起拷贝**，只复制 exe 会缺少 ffmpeg.dll 等依赖。
若只想要一个文件，请用上面的「方式 A」单文件便携版。

### 方式 C：浏览器模式（开发 / 调试用）

```bash
node serve.mjs            # 默认 5173 端口
node serve.mjs 8080       # 自定义端口
# 浏览器访问 http://127.0.0.1:5173/
```

> 也可执行 `npm start`。服务零依赖，仅用 Node 内置模块（http / fs / path），
> 静态根目录限定在 `src/`，已做目录穿越防护。

### 重新构建客户端

```bash
npm run build:portable        # 生成单文件便携版（dist-portable/）
npx electron-builder --win dir --x64   # 仅生成解包目录，便于调试
node build-client.mjs         # 用本机 Electron 缓存组装绿色目录版客户端
node build-client.mjs --force # 强制重新解压运行时
```

构建脚本优先复用 `%LOCALAPPDATA%/electron/Cache/electron-v33.4.11-win32-x64.zip`，
无网络时也能重建；如缓存不在默认位置，可设置环境变量 `ELECTRON_ZIP` 指定 zip 路径。

> 日常改代码后想快速验证，可用 `node sync-assets.mjs` 直接重建解包目录中的
> `app.asar`（约 2 秒），不必每次等完整打包。

## 二、功能总览

界面采用桌面工程软件通用布局：**标题栏 + 工作区标签 + 左侧专业导航树 + 中间参数/结果 + 右侧结果概览 + 底部状态栏**。
标题栏右上角可一键切换**白天 / 黑夜模式**，系统标题栏与自绘标题栏同步变色，选择自动保存，下次启动保持。

**参数化图纸（核心交互）**：选择任一模块后，参数区顶部显示该专业的矢量构造大样，按施工图习惯绘制——
混凝土/土体用剖面填充，构件分线宽，尺寸按**尺寸线 + 尺寸界线 + 45° 起止符 + 数值**标注（绿色），
并在图面上直接给出各控制尺寸的数值。点击图上的**尺寸数字或黄色参数标牌**即可改数，回车后模型与计算结果**实时刷新**；
无法落到几何上的参数（荷载、型号、坡比等）以标牌形式列在图上，同样可点击修改。
生成计算书时，图纸按当前参数静态内嵌到对应章节，打印友好。

**多视角模型（仿广联达）**：每个模块的模型都支持**立面图 / 俯视图 / 剖面图**多视角切换，
在模型面板标题栏点标签即可切换；切换后标注依旧可点改，改数后所有视角与计算结果同步刷新。
- 脚手架类：立面 + **俯视（立杆网格与连墙件布置）** + **剖面（两排立杆与剪刀撑）**；
- 模板支撑类：立面 + **俯视（立杆网格与主楞）** + **剖面（楼板、顶托、水平杆）**；
- 其余专业按性质提供俯视（基坑降水井布置、塔吊基础、边坡土钉、卸料平台平面、临边防护平面、
  起重吊装回转平面、临时用电与用水平面、防护棚平面、斜道平面、大体积混凝土测温平面等）。

**三维视角窗口**：模型面板点「三维视角」按钮打开**独立可旋转窗口**——
按住图面拖动即可实时改变观察角度，滚轮缩放，并提供「正面 / 侧面 / 俯视 / 轴测」预设；
窗口下方实时列出该模块的全部参数数值；主界面改任一参数，三维模型**立即重建**。
采用原生 SVG 等轴测投影实现，不依赖 WebGL，渲染稳定、零额外体积。

**方案与工具工作台（按广联达 GAQ 模板一比一对齐）**：
「方案与工具」标签页以**当前模块与参数**为基准，自动产出全套施工技术文件，全部可预览、打印、导出。
各功能的章节体例、表格字段与结论措辞均按广联达 GAQ 对应模板逐项对齐：

| 功能 | 广联达对应体例 | 本软件实现 |
|---|---|---|
| **施工方案生成** | `Designer/*.rtf` 专项方案模板 | **八章体例**：①编制依据及工程概况（第一节 编制依据：1 施工组织设计 / 2 计算软件及版本 / 3 工程图纸 / 4 施工规范及规程 / 5 其他；第二节 工程概况含参数表）②施工准备（技术准备 / 材料准备 / 人员及机具准备）③主要施工方法 ④质量标准及技术控制措施 ⑤拆除（拆除原则 / 拆除施工）⑥施工安全保证措施 ⑦文明施工要求 ⑧安全计算书（含材料优化评价表）。各专业提供独立的施工方法、材料、机具与质量条目，非通用套话 |
| **危险判断（自动）** | `SafeConsider/*.rtf` 危险性判断计算书 | 输出**判据参数表**（判据项 / 取值 / 取值来源）+ **清单条目比对表** + **三档规范结论措辞**：不属于危大工程（可不用编制专项施工方案，但应有安全技术保证措施）／危险性较大的分部分项工程（须编制专项方案，技术负责人签字、总监审核签字）／超过一定规模的危险性较大的分部分项工程（须编制专项方案并组织专家论证）。判据从模块字段自动提取，比对 37 号令附件一、附件二清单 |
| **设计图纸** | `DesignPicture/*.dwg` 施工图 | 输出 **A3 横向单张施工图**：图框 + 多视角视图自动排布 + **底部横条**（设计参数 / 图纸目录 / 主要材料三栏）+ **图签栏**（工程信息 / 设计依据 / 验算结论 / 签字栏），可直接打印或导出 SVG |
| **应急预案** | `Emergency/*.rtf` 现场应急预案 | **六章体例**：①编制目的及适用范围 ②危险源分析（事故类型与主要原因）③组织机构及岗位职责（领导小组 + 9 个部门职责）④应急响应及救援（启动条件 / 资源配备 / 四级响应 / 六步处置程序 / 应急终止与现场恢复）⑤应急演练（培训与演练 / 评审与改进）⑥危险源监控及预防（安全技术措施 / 杜绝违章作业 / 安全管理） |
| **材料统计** | `StatisticsMaterial/*.rtf` 材料统计表 | 统计口径对齐：**项目 / 单位 / 型号 / 数量 / 表达式 / 计算依据 / 备注** 七列。表达式列给出数量的推导算式（如「立杆 10×18 + 纵向水平杆 11×2×4×1.5 + 剪刀撑 2×√(1.8²+1.5²)×10」），另附损耗率与含损耗量，可直接作为采购与材料计划依据 |
| **评估优化** | `OptConclusion/*.rtf` 材料优化评价表 | 按构件（面板 / 次楞 / 主楞 / 立杆 / 水平杆 / 扣件 / 连墙件 / 可调托座 / 地基基础…）列出各验算项的**计算内容 / 计算值 / 允许值 / 材料使用性能(%)**，并给出**安全性与经济性双档结论**（≤50% 安全性极高但经济性极差；≤80% 安全与经济均合理；≤100% 安全性偏低）。同时保留「必须整改 / 建议优化 / 提示关注」三级建议，带参数的项支持**一键采纳**——回填参数表并自动重算 |

### 计算模块清单（35 个 / 8 大专业，覆盖广联达 GAQ 全部模块类型）

**脚手架工程（9）**：落地式扣件、型钢悬挑、承插型盘扣、碗扣式、门式、满堂脚手架/支撑架、架上楼板、斜道、电梯井脚手架。
依据 JGJ 130-2011、JGJ/T 231-2021（**替代已废止的 JGJ 231-2010**）、JGJ 166-2016、JGJ/T 128-2019、GB 55023-2022。

**模板工程（9）**：混凝土模板支撑体系、梁模板、柱模板、墙模板（木模/组合钢模/大钢模）、梁侧模板、悬挑支撑、单侧支模、楼梯模板、铝模盘扣支撑架。
依据 JGJ 162-2008、GB 50666-2011、GB 55008-2021、GB 50017-2017。

**基坑工程（3）**：基坑降水与支护、土方放坡开挖、土钉墙支护。依据 JGJ 120-2012、GB 55003-2021、GB 50007-2011。

**起重机械（4）**：起重吊装、塔吊基础、塔机附着、构件吊装（汽车吊/履带吊/双机抬吊）。依据 GB/T 3811-2008、GB/T 6067.1-2010、JGJ 196-2010、**GB/T 20118-2025 钢丝绳**。

**安全防护（4）**：临边与洞口防护、卸料平台与操作平台、防护棚、安全通道防护棚。依据 JGJ 80-2016、GB 55034-2022。

**混凝土工程（3）**：大体积混凝土温控、泵送混凝土、冬期施工热工（成熟度法/综合蓄热法）。依据 GB 50496-2018、JGJ/T 104-2011、JGJ/T 10-2011。

**临时工程（2）**：施工临时用电、施工临时用水。依据 **JGJ/T 46-2024（2025-01-01 实施）**、GB 50194-2014、GB 50015-2019、GB 55020-2021。

**地基工程（1）**：机械运行路线地基承载力。依据 GB 50007-2011。

> 每个模块 `meta.glodon` 字段标注了它对应的广联达 RTF 计算书模板名（品茗新增项标注为空数组），可在源码中逐项核验覆盖关系。

每个模块的每一项验算均输出：**计算式（含代入数值）→ 结果 → 限值 → 判定 → 依据条文号**，
并附带需要按地方标准 / 勘察报告 / 专项方案复核的提示。

## 四、自检

```bash
node tests/run-tests.mjs       # 模块结构自检：每项验算必须有名称/依据/计算式/布尔判定/非 NaN
node tests/check-assets.mjs    # 资源完整性：index.html 引用、js import、数据 JSON、模块可导入
node tests/check-views.mjs     # 多视角与三维模型：视角可渲染、标注 key 命中字段、3D 随参数变化
node tests/check-3d-rotation.mjs  # 三维旋转手感：灵敏度降低、Shift 精调、rAF 合帧、惯性收敛
```

## 五、洁净室合规边界

本项目在分析两个商业软件安装包（广联达 GAQ、品茗建筑施工云安全计算软件 2027 版）时，
**仅做静态资源层面的观察**（文件清单、配置项、界面素材、文档目录），
**不提取、不反编译、不复制**其任何代码、算法、数据库、图库或文档内容。

新软件的实现路径：

1. **公式来源**：公开的现行国家 / 行业标准条文原文；
2. **数据来源**：住建部官网公告、国家标准全文公开系统等公开渠道；
3. **截面特性**：一律由几何尺寸实时计算（`core/materials.js`），不抄录任何型钢表；
4. **图示**：全部为本软件自绘的 SVG 矢量大样（`core/drawing.js`），不使用任何 CAD 素材；
5. **验证方式**：每一项结论都可回溯到具体条文号，自检脚本强制校验这一约束。

详细取证方法与合规边界见 `docs/01-逆向分析报告.md`。

## 六、已知限制

- 部分限值（允许放坡系数、降水影响半径、容许挠度、地面荷载限值等）需按**地方标准、
  勘察报告或批准的专项方案**确定，软件将其做成了可覆盖的输入项，计算前须人工核对；
- 圆弧滑动稳定等岩土专业计算不在本软件范围内，模块仅按规范限值**对照**设计单位给出的结果；
- 危大工程判定为**参数化辅助判定**，最终结论须由项目负责人按专项方案与实际工况确认；
- 本软件输出为计算书**参考文本**，不替代施工组织设计、专项施工方案与专家论证。
